¿QUÉ ES MOTORLAB?

Aprender mecánica de una manera más visual

MotorLab es una aplicación web progresiva creada como proyecto educativo.

Su objetivo es facilitar el aprendizaje básico sobre los componentes de un automóvil utilizando una experiencia visual e interactiva.

En lugar de aprender únicamente mediante textos, el usuario puede explorar un modelo de automóvil y descubrir qué función cumple cada componente.

NUESTRO OBJETIVO

¿Qué queremos lograr?

🎯

Enseñar

👀

Utilizar modelos visuales para comprender mejor las piezas del automóvil.

💡

Experimentar

Tecnología + educación + interacción

MotorLab combina HTML, CSS y JavaScript con elementos interactivos para crear una experiencia educativa moderna.
